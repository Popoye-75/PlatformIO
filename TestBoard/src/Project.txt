1. PROJECT OBJECTIVE

The objective is to develop a two-wheel self-balancing robot using an Arduino Uno, an MPU6050 accelerometer and gyroscope, and an L298N motor driver.

The robot should maintain its upright position automatically using a PID control algorithm.

The system works by:

Measuring the robot's inclination using the MPU6050.
Calculating the tilt angle using accelerometer and gyroscope readings.
Filtering sensor noise using a complementary filter.
Calculating the correction using a PID controller.
Controlling both DC motors through the L298N driver.
Continuously adjusting motor speed and direction to maintain balance.

3.2 L298N to Arduino Uno
L298N Pin	Arduino Pin	Purpose
ENA	D10	Left motor PWM
IN1	D8	Left motor direction
IN2	D9	Left motor direction
ENB	D5	Right motor PWM
IN3	D6	Right motor direction
IN4	D7	Right motor direction
3.3 Important electrical considerations
Arduino GND, MPU6050 GND and L298N GND must be connected together.
Motors should use a suitable external motor power supply.
Do not power motors directly from Arduino 5V.
Ensure the battery can supply the motor's startup and stall current.
Check the L298N ENA and ENB jumper configuration before using PWM.
Keep motor power wiring away from sensitive MPU6050 signal wiring where possible.

7. BASIC MPU6050 TEST CODE

The following code was used to verify sensor communication.

cpp
#include <Arduino.h>
#include <Wire.h>

#define MPU 0x68

void setup()
{
    Serial.begin(9600);
    Wire.begin();

    Wire.beginTransmission(MPU);
    Wire.write(0x6B);
    Wire.write(0x00);

    byte error = Wire.endTransmission();

    if (error == 0)
        Serial.println("MPU6050 Connected!");
    else
        Serial.println("MPU6050 Not Found!");
}

void loop()
{
    Wire.beginTransmission(MPU);
    Wire.write(0x3B);
    Wire.endTransmission(false);

    Wire.requestFrom(MPU, 6, true);

    if (Wire.available() >= 6)
    {
        int16_t ax = Wire.read() << 8 | Wire.read();
        int16_t ay = Wire.read() << 8 | Wire.read();
        int16_t az = Wire.read() << 8 | Wire.read();

        Serial.print("AX: ");
        Serial.print(ax);
        Serial.print(" AY: ");
        Serial.print(ay);
        Serial.print(" AZ: ");
        Serial.println(az);
    }

    delay(500);
}


This code reads raw accelerometer values.

8. SELF-BALANCING ROBOT CONTROL SYSTEM

The robot uses three major software algorithms.

8.1 Accelerometer angle calculation

The accelerometer measures acceleration along three axes.

An angle can be estimated using:

cpp
float accelAngle = atan2(ax, az) * 180.0 / PI;


The correct axis combination depends on how the sensor is mounted.

8.2 Gyroscope angle calculation

The gyroscope measures angular velocity.

For the ±250 degrees/sec configuration:

cpp
float gyroRate = (gy - gyroOffsetY) / 131.0;


Angle integration:

cpp
angle = angle + gyroRate * dt;


The gyroscope requires calibration to compensate for its zero-rate offset.

8.3 Complementary filter

The complementary filter combines accelerometer and gyroscope readings.

Formula:

cpp
angle = 0.98 * (angle + gyroRate * dt)
      + 0.02 * accelAngle;


The gyroscope provides short-term responsiveness, while the accelerometer corrects long-term drift.

8.4 PID controller

The PID controller calculates the motor correction.

Formula:

text
Error = Measured Angle - Target Angle

PID = Kp * Error
    + Ki * Integral
    + Kd * Derivative


Initial experimental parameters:

Parameter	Value
Kp	22.0
Ki	0.0
Kd	0.9

These values are unverified starting values and must be tuned for the actual robot.

10. MOTOR CONTROL LOGIC

The current motor control function uses:

cpp
void setMotor(int left, int right)


Motor speed range:

text
-255 to +255


Positive values represent one direction and negative values represent the opposite direction.

The actual forward direction depends on motor wiring.

The L298N receives PWM signals through ENA and ENB.

Both motors currently receive the same PID correction.

Motor polarity and mechanical alignment must be checked before balancing tests.
